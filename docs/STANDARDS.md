# 遊戲美術與效能標準

店主要的（2026-11-28，第 844 項）：「你這邊有辦法定一個遊戲業界標準的.md嗎？」

這份是**照業界慣例整理、能用工具量的標準**。本專案自己的規則仍然優先，寫在：
- `CLAUDE.md` 的固定規則
- [`docs/MODELING.md`](MODELING.md)：建模流程
- [`docs/LOWPOLY.md`](LOWPOLY.md)：低面數做法
- [`docs/BAKING.md`](BAKING.md)：烘焙管線
- `docs/DETAILS.md`「效能」那一節

兩邊有衝突時照本專案的規則，這份只補上業界通用、專案還沒寫明的部分，並給每一條一個門檻與檢查方法。

數字的根據：
- 風格化（stylized）、低面數的 3D 遊戲，跑在瀏覽器（WebGL2、three.js）。
- 目標硬體由低到高：內顯筆電、中階獨顯桌機、高階桌機（第 800 項的三級）。
- 同一畫面約 30 個人物、200 件擺設。

## 一、佈線（Topology）

業界的共識是**乾淨、可預期的網格**：
- 好改、好烘焙，打光不出怪斑。
- 在線框裡看得懂每一圈線在做什麼。

| 規則 | 門檻（新模型必須做到） | 怎麼檢查 |
| :--- | :--- | :--- |
| 四邊形為主 | 建模時四邊形為主；三角形只在收尾、尖端；不留多邊形（n-gon），匯出前一律切成梯狀（`common.py` 的 `ladder_ngons`） | Blender 匯出時 `LADDERED_NGONS` 的數字 |
| 不從中心放射（fan） | 一個點最多 8 個三角形（極點，pole）；圓蓋、端面用梯狀（`ladder_fill`），不收成一點 | `scripts/topo-audit.mjs` 的 `pole`（紅線 10），`scripts/mesh-audit.mjs`（小物件紅線 12） |
| 不留扁三角（cap） | 一個角超過 150° 的三角形。這種三角形是多邊形用扇形或耳切法（earcut／EAR_CLIP）切出來的，在線框裡像噴射線。<br>**平滑曲面上的（soft caps）0 個**：三個角的法線方向不同，光沿著它的長邊拉成一條條紋。<br>**平的面上的（圓柱的端面、板子的正面）盡量少**：法線都一樣，打光看不出來，只有線框難看。任何十二邊以上的凸多邊形，只要中間不加點，不管怎麼切都會留兩個「耳朵」，所以一個圓形封口最多兩個。<br>長條四邊形對角切成的兩個細長三角（needle，角是直角）不算。 | `topo-audit.mjs` 的 `soft`（曲面上的）與 `caps`（全部） |
| 不留退化三角 | 面積為 0 的三角形 **0 個**（重複的點、首尾重疊的外形） | `topo-audit.mjs` 的 `dead` |
| 邊流跟著形狀 | 圓的東西用一圈一圈的環（ring）；轉角要圓就用 1～4 段倒角或支撐邊；硬邊與平滑邊分開（`set_sharp_from_angle` 30～40°） | 近拍，加上 Blender 的線框預覽 |
| 密度均勻 | 同一件物件裡，三角形大小差不超過約 10 倍；小零件不比大零件密 | `topo-audit.mjs` 的 `slivers` 比例只當參考 |
| 不穿模、不共面 | 兩件東西不互相插入超過 1.5 公分；兩個面不在同一平面（抬高 1 毫米以上，或用 `polygonOffset`） | `tests/e2e/clips.mjs`（`TOL` 1.5 公分） |
| 封閉與描線 | 要描黑線（`inkModel` 的背面外殼）的網格要封閉；薄片（布、葉、藤條）不描線 | 近看邊角有沒有黑刺（第 820、789 項） |

**禁止的做法**（每一條都在本專案出過事）：
- 用 Blender 的 `triangulate`（`EAR_CLIP`）切大的多邊形：花魚 `Hokke` 一點擠了 23 個三角形，第 843 項。
- 在凸包（convex hull）上套全邊倒角：爐框四角銅片出現退化三角，第 843 項。
- 把 earcut 用在大面上：料理台面、吧台面整片碎三角，第 954 項。

## 二、面數預算（Polycount）

業界在風格化、行動或網頁等級的常見範圍，換成本專案的類別：

| 類別 | 例子 | 三角面上限 | 說明 |
| :--- | :--- | :--- | :--- |
| 小擺設（< 25 cm） | 杯、碟、調味瓶、開關 | **100**（店主的鐵律） | 外圈 16～24 段；造型複雜、要保輪廓的例外寫進 `DETAILS.md` |
| 中型（25 cm～1 m） | 酒樽、盆栽、掛鐘、竹簾 | 600～1,500 | 圓的輪廓要段數，細節進貼圖 |
| 大型家具（> 1 m） | 長凳、櫃子、配膳台、收銀台 | 1,500～3,000 | 割竹、木紋這類細節一律進貼圖 |
| 主角級 | 灶台、神棚 | 5,000～10,000 | 近看的重點，可以多，但照第 574 項烘焙 |
| 人物 | 客人、員工 | ≤ 2,500 一個 | 同時約 30 個，共用骨架與材質 |
| 整個畫面 | 一般視角 | 低級 150k，中級 300k，高級 450k | 量法：右上角的 Tris、`__triTop`、`npm run bench` |

超過上限的要嘛減（`blender/optimize_glb.py`，減過的一定要近拍前後對照），要嘛把細節烘進貼圖（法線、AO）。

## 三、UV 與貼圖

| 規則 | 門檻 | 怎麼檢查 |
| :--- | :--- | :--- |
| 尺寸 | 2 的次方（256、512、1024）；單張上限 1024（Mac 512，`scene/render/textureCap`），圖集用 `userData.capScale` 保留兩倍 | `map.image.width` |
| 解析度一致（texel density） | 同一區的擺設大致一樣的「每公尺幾像素」（一般擺設約 512 px/m，主角級約 1024 px/m）；同一畫面不要有一件特別糊或特別銳 | 近拍並排 |
| 留邊（padding） | 圖集裡每塊之間留 4～8 px，邊緣向外擴色（dilate），縮圖時不滲色 | `slot_atlas` 的設定 |
| 色彩空間 | 顏色圖用 sRGB；法線、粗糙度這類資料圖用 linear；法線用 OpenGL（+Y，three.js 的慣例） | `pbr(..., data=True)` |
| 壓縮 | 大貼圖用 KTX2（Basis），一般圖用 JPEG／WebP，透明的用 PNG | `scene/render/ktx2` |
| 縮圖（mipmap） | 一般開；很小的發光點、精靈（sprite）關（第 781 項的灰塵） | 遠看有沒有閃、有沒有消失 |
| 字 | 畫進貼圖，不做成網格 | `common.py` 的 `DecalAtlas` |

## 四、材質、繪製次數與著色程式

| 規則 | 門檻 | 怎麼檢查 |
| :--- | :--- | :--- |
| 著色程式數 | 全場 ≤ 100；營業中 **不新編**（固定規則 7） | 右上角的 Prog；`tests/e2e/_rainprog834.mjs` 這類「事件前後程式表」 |
| 繪製次數（draw calls） | 一般視角：低級 ≤ 600、中級 ≤ 900、高級 ≤ 1,200 | 右上角的 Draw calls、`npm run bench` |
| 合併 | 不動的零件照材質合併（`StaticBatch`、`WorldBatch`）；同樣的東西 5 個以上用 InstancedMesh | `BY=1 node tests/e2e/perf.mjs` |
| 材質種類 | 用標準的 toon、standard、basic，不為小差別寫自訂 shader | `scene/render/materialNormalize` |
| 透明 | 能用 alphaTest 就不用混色；不用 transmission（固定規則 5）；透明的東西少疊 | 近看與 perf |
| 燈 | 執行中不增減燈、不用 `visible` 開關燈（固定規則 6）；強弱與陰影用參數調（`intensity`、`shadow.intensity`、`radius`） | Prog 不變 |

## 五、匯出（glTF／.glb）

- **座標與方向**：+Y 向上；遊戲裡的單位照各店的框架（吧台是「bar 單位」，是公尺的兩倍）；腳底中心當原點（吊掛的在中心，`HANGS`）。
- **變形**：套用旋轉與縮放（apply）；節點名稱用英文 PascalCase，跟程式裡找的名字一致。
- **材質**：每個材質有名字；沒用到的材質與貼圖不匯出。
- **頂點色**：放在 `COLOR_0`（`export_dish` 會處理），用來放烘好的 AO 與色差。
- **完整檢查清單**：[`docs/BAKING.md`](BAKING.md)「三、glTF／.glb 匯出強制檢查清單」。

## 七、動畫與特效

- **動畫十二法則**：預備動作、餘勢與跟隨、緩入緩出、時間節奏，人物與物件都照做。例如貓時鐘的尾巴尖晚一拍（第 827 項），水滴照重力先慢後快（第 834 項）。
- **跟幀率無關**：動畫用 `dt`，而且限制上限（例如 `Math.min(dt, 0.05)`），掉幀不跳。
- **粒子**：一種效果一個 InstancedMesh；同時看得到的粒子 ≤ 500；不用時藏起來，但著色程式在載入時就編好。
- **回饋**：每個可點的東西都有提示（`setTip`），每個面板開關都有聲音（`usePanelSound`）。
